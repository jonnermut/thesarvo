## Docs and private information

All docs, operational scripts (AWS setup and deploy, Confluence import and sync; they live in `thesarvo-private/scripts`) and any private information (plans, as-built records, AWS account details, addresses, anything sensitive) go in the **private** repo
`thesarvo-private` (https://github.com/jonnermut/thesarvo-private), which must be checked out as a peer of this repo (`../thesarvo-private`;
`gh repo clone jonnermut/thesarvo-private` if missing). This repo is public: never put docs or private information in it.
